# Reference data

The acetone spectrum in `synthetic_data/67-64-1-IR.jdx` is from the NIST Chemistry WebBook, SRD 69, Coblentz No. 08767:
https://webbook.nist.gov/cgi/cbook.cgi?ID=C67641&Index=2&Type=IR-SPEC

Credit NIST and the Coblentz collection when using this spectrum. The software license does not replace source data terms. The spectrum defines relative absorption, not the absolute simulated optical scale. All patient observations in this repository are synthetic.
